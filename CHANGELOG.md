## [1.0.11] - 2026-10-07

### Added

- **TCP-предпроверка перед Xray-проверкой.**
  - Перед запуском Xray на каждой ссылке — TCP-connect к серверу.
  - Если latency > `TCP_PRECHECK_MAX_LATENCY_MS` (2000 мс) или connect не удался — Xray **не запускается**.
  - Экономия CPU и времени на заведомо мёртвых серверах.
  - Новые параметры: `TCP_PRECHECK_ENABLED`, `TCP_PRECHECK_TIMEOUT`, `TCP_PRECHECK_MAX_LATENCY_MS`.

- **Перемешивание списка перед проверкой.**
  - Перед началом проверки чанками — список **перемешивается один раз**.
  - Чекер не идёт по списку сверху вниз, а берёт случайные ссылки.
  - Не ломает логику чанков.
  - Новый параметр: `SHUFFLE_BEFORE_CHECK`.

### Changed

- **Лог финала** — добавлен счётчик TCP-отсеянных: `(TCP-отсеяно: N)`.

## [1.0.10] - 2026-10-07

### Fixed

- **Observer сбрасывает `dead_links` при обновлении файла ссылок.**
  - **Проблема:** если ссылка была помечена мёртвой (в `dead_links`), а чекер через 6 часов её снова нашёл и сохранил в `working_links.txt` — observer её **игнорировал** до рестарта.
  - **Причина:** `dead_links` — в памяти, не синхронизирован с файлом.
  - **Решение:** при **изменении** `working_links.txt` (сравнение через `set`) — `dead_links` **сбрасывается**.
  - Теперь ожившая ссылка, сохранённая чекером — **снова доступна** observer'у без рестарта.

### Changed

- **`update_pool_from_file`** — сравнивает старый и новый списки через `set`, при изменении сбрасывает `dead_links`.

## [1.0.9] - 2026-10-06

### Changed

- **Дедупликация ссылок по `(host, uuid)` вместо `host`.**
  - Раньше: если на одном хосте несколько ссылок с разными UUID — сохранялась только **одна** (с лучшим пингом). Остальные отсеивались.
  - Теперь: ключ дедупликации — **`host_uuid`**. Разные UUID на одном хосте — **разные ссылки**.
  - В `save_working_links` — `host_best` → `best_by_key`, добавлено извлечение UUID из ссылки.
  - Позволяет сохранить **больше ссылок** (ближе к `STAGE1_WORKING_COUNT = 30`).

### Note

- **Функциональность observer'а не изменилась.** Работает как в 1.0.8.
- **Изменён только `save_working_links` в `vless_checker.py`.**
