## [1.0.8] - 2026-09-25

### Added

- **Дополнительные поля в ответе `/tmp/vless_links_response`.**
  - **`dead`** теперь отдаёт **список объектов** `{link, host, country}` вместо сырых ссылок.
  - **`deferred`** теперь содержит поле **`deferred_min`** — сколько минут ссылка находится в отложенных.
  - **`primary`** и **`quarantine`** приведены к тому же формату `{link, host, country}`.
  - Поле **`link`** — полная ссылка. Поля **`host`** и **`country`** — извлечены из неё.

- **Новая вспомогательная функция `_link_info(link)`** в `triggers.py`.
  - Формирует объект `{link, host, country}` для любой ссылки.
  - Используется для всех списков в ответе.

### Changed

- **Формат `handle_links` унифицирован.**
  - Раньше: `dead` — сырые ссылки, `deferred` — без времени.
  - Теперь: все списки — объекты с **одинаковыми полями**, deferred содержит **время**.

### Fixed

- **Неинформативный вывод `/links` в Telegram-боте.**
  - Раньше: бот получал **сырые ссылки** для мёртвых, не мог показать **хост и страну** без парсинга на своей стороне.
  - Теперь: observer **сам** отдаёт `host` и `country` — бот просто **форматирует**.

### Note

- **`observer.py`, `vless_common.py`, `observer_config.py` — не менялись.**
- Изменён только **`triggers.py`**.

## [1.0.7] - 2026-09-22

### Added

- **Двойная проверка резервных ссылок.**
  - Новая функция `test_link_double_check` в `vless_common.py`.
  - Перед добавлением в резерв ссылка проверяется **N раз с интервалом**.
  - В резерв попадают только те, которые **ВСЕ N проверок** прошли успешно.
  - Отсеивает ссылки, которые отвечают **1 раз из N** — нестабильные.

- **Проверка перед переключением.**
  - В `switch_to_backup` — перед тем как поставить ссылку как основную, observer **проверяет её прямо сейчас**.
  - Если ссылка **мертва** — в deferred, берётся **следующий** кандидат из пула.
  - **Больше не переключаемся на мёртвую.**

- **Новые параметры в `observer_config.py`:**
  ```python
  # Сколько раз проверять ссылку перед добавлением в резерв.
  BACKUP_CHECK_ATTEMPTS = 2

  # Пауза между проверками (сек).
  BACKUP_CHECK_INTERVAL = 2
  ```

- **Устойчивое чтение параметров** в `vless_common.py`.

### Changed

- **Логи стали информативнее.**
  - При пополнении резерва:
    ```
    🔎 Проверяем кандидата [1]: 31.76.39.141 [GB] (2 проверок, интервал 2с)...
    ❌ 31.76.39.141 [GB] не прошла 2 проверок — в deferred
    🔎 Проверяем кандидата [2]: 147.45.148.6 [RU] (2 проверок, интервал 2с)...
    ✅ 147.45.148.6 [RU] живая — в резерв [4/4] (пинг: 583мс)
    ```
  - При переключении:
    ```
    🔎 Проверка перед переключением: 31.76.57.191 [DE]...
    ✅ 31.76.57.191 [DE] жива (пинг: 747мс) — переключаемся
    ```

- **Логи при старте observer'а** — добавлены строки:
  ```
  Двойная проверка резерва: 2 раз, интервал 2с
  Проверка перед переключением: включена
  ```

### Fixed

- **Проблема «резервные вроде есть, но при переключении связь сразу падает».**
  - Раньше: одна успешная проверка давала ложное «жива».
  - Теперь: ссылка проходит **двойную проверку** при добавлении в резерв и **проверку перед переключением**.

## [1.0.6] - 2026-09-22

### Added

- **Приоритетная страна (`PREFERRED_COUNTRY`).**
  - Если задан код страны — observer в первую очередь берёт ссылки с этой страной.
  - Если пустая строка — приоритета нет.
  - Если код невалидный — игнорируется с предупреждением.
  - Приоритет — **не ограничение**: если ссылок с этой страной нет, observer добирает из остальных.

- **Система триггеров через файлы в `/tmp/`** (`triggers.py`).
  - Управление observer'ом из Telegram-бота или вручную.
  - **Проверка свежести:** триггер старше `TRIGGER_MAX_AGE` (30 сек) удаляется без выполнения.
  - **Чистка при старте:** все старые триггеры удаляются при запуске observer'а.
  - **Ответы** — в `/tmp/vless_<action>_response` в формате **JSON**.

- **Триггеры:**

  | Файл | Действие |
  |------|----------|
  | `/tmp/vless_status_trigger` | Запрос статуса |
  | `/tmp/vless_links_trigger` | Список всех ссылок |
  | `/tmp/vless_switch_trigger` | Переключиться на следующую |
  | `/tmp/vless_geo_DE` | Переключиться на страну DE |
  | `/tmp/vless_pick_46.28.69.53` | Переключиться на host |
  | `/tmp/vless_ignore_46.28.69.53` | В карантин |
  | `/tmp/vless_unignore_46.28.69.53` | Из карантина |
  | `/tmp/vless_reload_trigger` | Перечитать файл ссылок |

- **Новый модуль `vless_common.py`** — общие функции для `observer.py` и `triggers.py`.

- **Новый модуль `triggers.py`** — логика всех триггеров.

- **Новые параметры в `observer_config.py`:**
  ```python
  PREFERRED_COUNTRY = ""
  TRIGGER_MAX_AGE = 30
  ```

### Changed

- **`observer.py` разделён на модули.**
  - `vless_common.py` — общие функции.
  - `triggers.py` — триггеры.
  - `observer.py` — логика observer'а.

- **`test_primary` сначала проверяет триггеры.**

- **`install.sh` и `update.sh` обновлены** — скачивают новые модули.
