# VLESS CHECKER — комбайн по сбору рабочих ссылок и их автообновлению в панели 3x-ui
В качестве сервера используется NanoPi Neo (можно любое подобное Raspberry, Orange и т.д., но выбранная модель более чем подходит для данной задачи) в связке с домашним Keenetic для DDNS (можно и другой роутер и другой сервис DDNS).
Структура работы:
1. На сервер устанавливаем панель 3x-ui, используется её модуль XRAY, балансировщик и обсерватория
2. Собственная сеть Keenetic обеспечивает доступ к серверу по доменному имени
3. Сборщик тестирует ссылки на работоспособность и обновляет конфиг 3x-ui

## 📋 Инструкция по установке
Предполагается, что на NanoPi установлена последняя версия Armbian(Debian 13) с официального сайта. Вставляем кабель LAN в роутер, подаем питание, смотрим IP адрес, который роутер назначил NanoPi, фиксируем его как статический. Подключаемся по SSH, задаем свой пароль, имя не надо.
### Шаг 1. Базовая настройка Keenetic
Заходим в меню Keenetic в пункт "Доменное имя" занимаем свободное имя третьего уровня, получится что-то типа xxxxxxxxx.netcraze.link. Режим работы - через облако. Галку доступа из интернета в этом пункте можно не включать, чтобы боты не долбили.
Далее добавляем "Доступ к веб-приложениям..." задаем имя сервиса, например npi. Получится npi.xxxxxxxxx.netcraze.link. Протокол HTTP, порт 80. Это нужно для выпуска сертификата в дальнейшем. Потом в этом пункте будет изменение
Пробрасываем порт 443 на устройсто(IP адрес) NanoPi.

### Шаг 2. Базовая настройка NanoPi
Подключаемся по SSH, вводим:
```bash
apt update && sudo apt upgrade -y
```
Добейтесь безошибочного исполнения обновления, иногда репозитории зарубежные притормаживают, можно через квн обновить.

### Шаг 3. Установка 3x-ui
Саму панель устанавливаем по методичке [по ссылке](https://noname-28.gitbook.io/3x-ui-gaid/nastroika-servera), начать с вкладки "Настройка сервера"





Шаг 3. Создание Outbound'ов в панели 3x-ui
Откройте веб-панель, создайте 10 outbound'ов:

vless_1, vless_2, ..., vless_10

Протокол: vless

Шаг 4. Установка VLESS Checker
bash
wget -qO- https://raw.githubusercontent.com/PsoyNe/vless_cascade/refs/heads/main/install.sh | bash
Шаг 5. Первый ручной запуск (через nohup)
bash
cd /root/vless_checker && nohup python3 full_check.py >> /var/log/vless_full.log 2>&1 &
tail -f /var/log/vless_full.log
Шаг 6. Добавление задания в cron
bash
crontab -e
Добавьте строку:

bash
# VLESS CHECKER — полный цикл каждую ночь в 2:00
0 2 * * * /root/vless_checker/run_full_check.sh
Шаг 7. Проверка
bash
crontab -l | grep vless_checker
Готово! 🚀
