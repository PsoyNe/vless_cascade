# VLESS CHECKER — комбайн по сбору рабочих ссылок и их автообновлению в панели 3x-ui
В качестве сервера используется NanoPi Neo (можно любое подобное Raspberry, Orange и т.д., но выбранная модель более чем подходит для данной задачи) в связке с домашним Keenetic для DDNS (можно и другой роутер и другой сервис DDNS). Используются списки ссылок vless из свободного доступа. В конфиге по умолчанию используются списки товарища по ссылке - https://github.com/ebrasha

Структура работы:
1. На сервер устанавливается панель 3x-ui, используется её модуль XRAY, балансировщик и обсерватория
2. Собственная сеть Keenetic обеспечивает доступ к серверу по доменному имени
3. Сборщик тестирует ссылки на работоспособность и обновляет конфиг 3x-ui

├── 📄 vless_check_config.py # Единый конфигурационный файл

├── 📄 working_links.txt # Пул ссылок (создаётся)

└── 📄 stable_links.txt # ТОП-10 ссылок (создаётся)

## 📋 Инструкция по установке
Предполагается, что на NanoPi установлена последняя версия Armbian(Debian 13) с официального сайта.
Вставляем кабель LAN в роутер, подаем питание, смотрим IP адрес, который роутер назначил NanoPi, фиксируем его как статический. Подключаемся по SSH, задаем свой пароль, имя не надо.
### Шаг 1. Базовая настройка Keenetic
Заходим в меню Keenetic в пункт "Доменное имя" занимаем свободное имя третьего уровня, получится что-то типа xxxxxxxxx.netcraze.link. Режим работы - через облако. Галку доступа из интернета в этом пункте можно не включать, чтобы боты не долбили.
Далее добавляем "Доступ к веб-приложениям..." задаем имя сервиса, например npi. Получится npi.xxxxxxxxx.netcraze.link. Протокол HTTP, порт 80. Это нужно для выпуска сертификата в дальнейшем. Потом в этом пункте будет изменение.
Пробрасываем порт 443 на устройсто(IP адрес) NanoPi.

### Шаг 2. Базовая настройка NanoPi
Подключаемся по SSH, вводим:
```bash
apt update && sudo apt upgrade -y
```
Добейтесь безошибочного исполнения обновления, иногда репозитории зарубежные притормаживают, можно через квн обновить.

### Шаг 3. Установка и настройка 3x-ui
Саму панель устанавливаем по методичке [по ссылке](https://noname-28.gitbook.io/3x-ui-gaid/nastroika-servera), начать с вкладки "Настройка сервера"
1. Первый блок кода по файерволу пропускаем
2. Во втором блоке и далее **yourdomain.com** - это наш домен полученный в Шаге 1 **npi.xxxxxxxxx.netcraze.link**.
3. Делаем всю настройку до конца.
4. Далее заходим через браузер по ссылке, которую выдала установка 3x-ui, заменив npi.xxxxxxxxx.netcraze.link в ссылке на IP адрес устройства в сети Keenetic(например было https://npi.xxxxxxxxxxx.netcraze.link:12853/BjRvDU3ekQS1g1eCy6 стало **http://192.168.1.15**:12853/BjRvDU3ekQS1g1eCy6, https тоже убрать букву S в ссылке)
5. Произвести первичную настройку XRAY по ссылке выше во вкладке "Настройка 3x-ui"
6. Поменять в Keenetic в разделе Доменное имя,"Доступ к веб-приложениям..." для npi.xxxxxxxxx.netcraze.link протокол HTTPS, порт 443
7. Проверить работоспособность тоннеля, создав клиента и подключив его через приложение. Учесть, что адрес сервера в настройках для работы внутри сети будет IP устройства, если подключение из сети за домашней сетью, то адрес сервера наш - **npi.xxxxxxxxx.netcraze.link**
8. Зайти в панели в исходящие, добавить 10 соединений vless с именами vless_1, vless_2......vless_10. Ссылку взять любую для добавления для всех соединений, даже нерабочую, мы ее потом заменим. Ссылку вставлять во вкладку JSON, нажать импорт.
9. Перейти в настройки конфигурации Xray->Балансировщик. Создать балансировщик, выбрать созданные vless с 1 по 9. Fallback выбрать direct. Назвать Balance1
10. В обсерватории балансировщика URL - https://check.torproject.org, время опроса 30s, параллельно.
11. Зайти в маршрутизацию, создать маршрут: выбрать только Тэг входящего(созданный в п.5), и Тэг балансировщика Balance1, остальное не трогаем.
12. Нажать сверху кнопку сохранить. Если пишет ошибку проверяйте что сделали не так, может что-то с соединениями.


### Шаг 4. Установка VLESS Checker
В SSH серверу на NanoPi ввести:

```bash
wget -qO- https://raw.githubusercontent.com/PsoyNe/vless_cascade/refs/heads/main/install.sh | bash
```
Поставить комбайн.

### Шаг 5. Первый ручной запуск (через nohup)
Далее ввести
```bash
cd /root/vless_checker && nohup python3 full_check.py >> /var/log/vless_full.log 2>&1 &
tail -f /var/log/vless_full.log
```
Ждать пока обработаются ссылки. В зависимости от провайдера 1.5-2 часа, может дольше.
Проверить командой top по процессам xray, будут появляться и пропадать, значит работают

### Шаг 6. Добавление задания в cron
Ввести:
```bash
crontab -e
```
Добавьте строку в конец:
```bash
# VLESS CHECKER — полный цикл каждую ночь в 2:00
0 2 * * * /root/vless_checker/run_full_check.sh
```
Сохранить. Теперь будет запускаться ночью в 2:00 и обновлять рабочие ссылки.(Проверьте системное время, после установки системы может быть +0:00)
Проверить:
```bash
crontab -l | grep vless_checker
```
